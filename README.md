Description:
The objective of this project is to design, construct, and evaluate a 4-wheeled autonomous prototype equipped with Active Trajectory Stabilization (Electronic Stability Program - ESP / Active Torque Vectoring). The vehicle utilizes Ackermann steering geometry on the front axle controlled by a digital servo motor, and independent rear-wheel drive powered by two DC gear motors with quadrature encoders. By fusing data from an Inertial Measurement Unit (IMU) and wheel encoders, the control system running on an STM32 Microcontroller will detect vehicle yaw rate deviations and dynamically adjust rear-wheel torque to prevent oversteer/understeer during high-speed cornering or low-friction maneuvers.

Hardware:
-Microcontroler: STM32H5 (Board: Nucle STM32H533RE)
